LLM triage with guardrails

LangGraph pipeline: rules baseline, LLM with schema validation, confidence fallback and a safety floor. Evaluated on a labelled set.

🩺

RAG first aid

Multilingual retrieval over vetted first-aid guides with query rewriting, scope detection and a refusal policy for doses.

⏱️

Severity-aware escalation

Critical incidents escalate 4× faster. Celery workers, Redis, row locks so only one responder “wins”.

🏢

Self-service societies

Register a society, flats are generated, residents join with a 6-letter code and the manager approves.

👨‍👩‍👧

Guardian circle

Residents invite family as guardians with a one-time link and set the alert order (P1, P2…).

🛡️

Built for production

Docker, PostgreSQL, throttling, LLM budget caps, health checks and a cron fallback for free hosting.

Add your own building in 3 steps

  1. Create an account and register your society: name, number of towers, floors and flats per floor.
  2. Share the join code (or link) on your society WhatsApp group. Residents, guards and volunteers request to join.
  3. Approve requests from the manager page. Residents add their guardians from “My circle”. Done.
